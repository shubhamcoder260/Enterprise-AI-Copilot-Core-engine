# CogniCore Frontend
React 19 + Vite 7 SPA. Chat UI: sessions, source badges (TOOL/DYNAMIC/LLM/FALLBACK),
SQL inspector, data tables, DB upload/switch, model picker, history hydration.
## Run
npm install
npm run dev      # dev server (proxies API to localhost:5000)
npm run build    # production build
## Backend
Requires the backend running on :5000 — see root GETTING_STARTED.md.
